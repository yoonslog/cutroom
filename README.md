# 컷룸 (CutRoom)

브라우저와 Windows에서 쓰는 무료 영상 편집기.

- 다운로드 사이트: https://yoonslog.github.io/cutroom/
- 웹에서 바로 쓰기: https://yoonslog.github.io/cutroom/app/

## 폴더
- `app/` 웹 편집기
- `download/` Windows 앱 (zip)
- `update/` 앱 자동 업데이트(manifest.json + resources.neu)
- `firebase/database.rules.json` Firebase Realtime Database 보안 규칙
- `fb-config.js` Firebase 웹 앱 설정
