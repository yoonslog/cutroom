v1.4.2

키프레임 가속 · 애니메이션 컨트롤

2026년 11월 22일
  • 키프레임 가속: 타임라인의 키프레임(◆)을 우클릭하면 선형 · 천천히 시작 · 천천히 끝 · 부드럽게 · 튕김 · 정지 등으로 바꿉니다
  • 효과 컨트롤 옆에 애니메이션 컨트롤 탭 — 노란 점을 끌어 가속 곡선을 직접 조절하고, 움직이는 공으로 바로 확인합니다
  • 자막이 화면 폭을 넘으면 자동으로 줄을 바꿉니다 (기본 그래픽 → 텍스트 → 자동 줄바꿈 · 줄 최대 폭)
  • 문자 도구(T)로 자막을 누르면 새 자막이 겹쳐 생기던 오류, Esc 뒤에도 문자 도구가 남던 오류 수정
  • 예시 프로젝트 · 쇼츠 · 노래방 시작 화면에 엉뚱한 템플릿(숫자 카운터)이 들어가던 오류 수정
  • 화면에서 자막을 고칠 때 입력 칸이 자막 자리에 정확히 겹치도록 수정, 빈 자막은 자동으로 지움
  • 긴 영상 · 많은 클립에서 타임라인이 가볍게 — 파형 · 썸네일을 다시 그리지 않고 재사용
