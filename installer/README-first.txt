Velo 영상 편집기 (Windows) v{VER}

이 폴더는 설치 없이 쓰는 압축본입니다. 설치 파일(Velo-Setup.exe)을 쓰면
바탕화면·시작 메뉴 아이콘이 생기고 설정 → 앱에서 제거할 수 있습니다.

1. Velo.exe를 두 번 눌러 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행"을 누르세요.
   (서명되지 않은 개인 제작 앱이라 나오는 경고입니다.)
3. resources.neu 파일은 Velo.exe와 같은 폴더에 있어야 합니다.
4. 새 버전이 나오면 앱이 알아서 받아 두고, 아래쪽에 "지금 다시 시작" 알림이 뜹니다.
5. Windows 10/11에 기본으로 들어 있는 Edge WebView2로 돌아갑니다.
